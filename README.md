# Практическая работа № 3 — Bootstrap 5 и JavaScript

## Назначение
Адаптивная панель учебных проектов: четыре KPI, последние действия, задачи с прогрессом, форма в модальном окне, offcanvas/accordion и toast. Интерфейс использует Bootstrap 5.3.3 CSS и **bootstrap.bundle.min.js**. Для Bootstrap CDN требуется интернет.

> **Важно:** к сообщению с заданием не приложен оригинальный архив `dataset`. Поэтому в репозитории лежит **отдельно подготовленный демонстрационный набор** `dashboard.json` и `notifications.json` и простые SVG для работы интерфейса. Это **не оригинальные значения преподавателя**. До окончательной сдачи замените их на выданные файлы dataset и при необходимости сопоставьте названия полей с `js/app.js`.

## Запуск (обязательно через локальный сервер)
Поскольку `js/app.js` загружает JSON через `fetch()`, **двойное нажатие на `index.html` в Проводнике не подходит**: браузер может заблокировать запросы к локальным файлам.

1. Откройте папку проекта в VS Code.
2. Если установлен Python 3, выполните в терминале: `python -m http.server 8000` (на Windows также `py -m http.server 8000`).
3. Откройте `http://localhost:8000` в браузере.
4. Либо откройте `index.html` через расширение **Live Server** в VS Code.
5. Для работы модальных окон, offcanvas и toast нужен интернет для CDN Bootstrap.

## Структура
- `index.html` — семантическая разметка, Bootstrap-компоненты.
- `css/custom.css` — только небольшие собственные детали оформления.
- `js/app.js` — загрузка JSON, преобразование данных в DOM, проверка формы и события.
- `dataset/dashboard.json` — **демонстрационные** показатели, действия и задачи.
- `dataset/notifications.json` — **демонстрационные** данные уведомлений.
- `dataset/assets/avatar.svg`, `dataset/assets/chart.svg` — иллюстрации.
- `docs/answers.md` — ответы для защиты.

## Что делает Bootstrap и что делает app.js
**Bootstrap CSS**: сетка `container/row/col`, готовые отступы и карточки, формы, таблица. **Bootstrap JS**: navbar collapse, modal, offcanvas, accordion и toast (через `bootstrap.bundle.min.js`). **Собственный JS**: `fetch` и загрузка JSON, генерация метрик/таблицы/задач, обработчики ввода и сохранения, переключатели задач, подсчёт прогресса, обновление данных, вызов `bootstrap.Toast.getOrCreateInstance` и `bootstrap.Modal.getOrCreateInstance`.

## Проверка
1. Ширины **375 и 1440 px** в DevTools; проверить мобильное раскрытие navbar и отсутствие прокрутки всего сайта по горизонтали.
2. Проверить четыре карточки показателей, таблицу и отметки задач.
3. Открыть **Добавить запись**: пустой/некорректный email или короткое название подсвечиваются через `is-invalid`, валидные поля — `is-valid`.
4. Сохранить валидную запись — новая строка таблицы и toast.
5. Открыть **О панели** — offcanvas и accordion; отдельно проверить кнопку **Показать уведомление**.
6. Убедиться, что в Console нет ошибок при нормальном запуске через сервер.

При обновлении страницы новые записи и отметки задач сбрасываются, потому что это учебная клиентская демонстрация без сервера сохранения.
