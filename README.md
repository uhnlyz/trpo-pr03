# Практическая работа № 3
### Bootstrap 5, Bootstrap JavaScript и базовый JavaScript интерфейса

**ПроектКонтроль** — адаптивная административная панель для отображения показателей учебных проектов, последних действий и текущих задач.

## Функциональность

- Четыре карточки показателей с данными из JSON.
- Таблица последних действий и список задач с расчётом прогресса.
- Модальная форма добавления записи с клиентской проверкой полей.
- Уведомления Toast после действий пользователя.
- Адаптивная навигация Navbar/Collapse, боковая панель Offcanvas и Accordion.
- Обновление данных и интерфейса без перезагрузки страницы.

## Технологии

- **Bootstrap 5.3.3** — сетка, компоненты и утилитарные CSS-классы.
- **Bootstrap JavaScript Bundle** — управление Modal, Toast, Collapse, Offcanvas и Accordion.
- **JavaScript** — Fetch API, обработчики событий, проверка полей и обновление DOM.
- **HTML5, CSS3** — разметка и дополнительные стили.

## Организация проекта

| Путь | Назначение |
| --- | --- |
| `index.html` | Разметка панели и Bootstrap-компоненты |
| `css/custom.css` | Дополнительные стили интерфейса |
| `js/app.js` | Загрузка данных и интерактивная логика |
| `dataset/dashboard.json` | Показатели, действия и задачи |
| `dataset/notifications.json` | Содержимое уведомлений |
| `dataset/assets/` | SVG-иллюстрации |

В текущей версии `dataset/` содержит **демонстрационные данные**. Отображаемые показатели и уведомления загружаются из этих JSON-файлов при работе приложения.

## Запуск

Поскольку для чтения JSON используется `fetch()`, страницу следует открывать через локальный HTTP-сервер. Например, при наличии Python 3 из корня проекта:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000` в браузере. Альтернативный вариант — локальный сервер расширения Live Server для VS Code.

Для загрузки Bootstrap через CDN требуется подключение к интернету.

## Логика работы

`js/app.js` получает данные из `dataset/` и формирует карточки, таблицу и список задач. Собственные обработчики реагируют на отправку формы, изменение задач и нажатия кнопок. Bootstrap JavaScript отвечает за поведение готовых компонентов. Новые записи хранятся в памяти страницы и сбрасываются при повторной загрузке.
