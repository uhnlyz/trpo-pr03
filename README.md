# Практическая работа № 3 — Bootstrap 5 и JavaScript

## Назначение

**Панель состояния** — адаптивный интерфейс для отображения четырёх показателей, списка операций и сводки по статусам. Работа показывает разницу между готовыми компонентами Bootstrap и собственной логикой JavaScript.

## Что реализовано

- Навигация Bootstrap Navbar с мобильным Collapse.
- Сетка `container`, `row`, `col` и четыре карточки показателей.
- Таблица операций в responsive-контейнере.
- Форма Bootstrap в модальном окне: проверка названия, email и статуса.
- Offcanvas-панель с Accordion.
- Toast-уведомления, текст которых берётся из `dataset/notifications.json`.
- Не менее трёх собственных обработчиков событий: отправка формы, проверка полей, кнопки уведомления и обновления.
- Программное управление компонентами через `bootstrap.Modal.getOrCreateInstance()` и `bootstrap.Toast.getOrCreateInstance()`.
- Сводка по статусам рассчитывается на основе массива `rows`.

## Исходные данные

В репозитории используются файлы из набора задания без изменения структуры:

- `dataset/dashboard.json` — четыре показателя и восемь операций в массиве `rows`.
- `dataset/notifications.json` — два уведомления с полями `type` и `text`.
- `dataset/assets/avatar.svg` и `dataset/assets/chart.svg` — иллюстрации из набора задания.

Приложение загружает JSON через Fetch API, а затем формирует карточки, строки таблицы и сводку по статусам. Эти файлы не просто хранятся в репозитории — их значения используются в интерфейсе.

## Структура проекта

- `index.html` — разметка и компоненты Bootstrap.
- `css/custom.css` — небольшие дополнительные стили.
- `js/app.js` — загрузка данных, отображение и обработчики событий.
- `dataset/` — исходные JSON и SVG из задания.
- `docs/answers.md` — краткие ответы для защиты.

## Запуск

Так как приложение читает JSON через `fetch()`, открывайте страницу через локальный HTTP-сервер, а не двойным щелчком по HTML.

1. Откройте папку проекта в VS Code.
2. В меню **Terminal → New Terminal** откройте терминал в корне проекта.
3. Если установлен Python 3, выполните:

   ```bash
   python -m http.server 8000
   ```

   В Windows также можно использовать `py -m http.server 8000`.
4. Откройте в браузере `http://localhost:8000`.

Можно также использовать расширение Live Server в VS Code. Для загрузки Bootstrap с CDN требуется интернет.

## Что делает каждый слой

- **Bootstrap CSS** оформляет сетку, карточки, кнопки, форму, таблицу и адаптивные компоненты.
- **Bootstrap JavaScript Bundle** управляет Collapse, Modal, Offcanvas, Accordion и Toast.
- **Собственный `app.js`** читает JSON, безопасно вставляет значения в DOM, валидирует поля, добавляет запись в текущий список и пересчитывает сводку.

Новая запись существует только в памяти страницы. Она не отправляется на сервер и исчезает после перезагрузки или повторной загрузки исходных данных.

## Проверка перед сдачей

1. Откройте сайт через локальный сервер и проверьте Console в DevTools.
2. Проверьте ширины 375, 768 и 1440 px.
3. Убедитесь, что видны четыре показателя и восемь исходных операций.
4. Откройте модальное окно и попробуйте отправить пустую форму.
5. Введите неправильный email и проверьте подсветку `is-invalid`; затем заполните форму корректно.
6. Сохраните запись: таблица и сводка должны обновиться, а Toast показать текст из JSON.
7. Проверьте мобильное меню, Offcanvas и Accordion.
