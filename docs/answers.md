# Краткие ответы для защиты — практическая работа № 3

**1. Какие входные данные использует приложение?**  
Файл `dataset/dashboard.json` содержит четыре показателя и восемь операций в массиве `rows`. Файл `dataset/notifications.json` содержит два уведомления с типом и текстом. Оба файла загружаются через `fetch()`.

**2. Где данные превращаются в интерфейс?**  
Функция `loadData()` загружает и проверяет JSON. `renderMetrics()` формирует карточки, `renderRows()` — строки таблицы, `renderStatusSummary()` считает количество операций по статусам и долю записей «Готово».

**3. Какой ошибочный сценарий проверялся?**  
Пустое название, слишком короткое название, неправильный email и невыбранный статус. Функция `validateField()` проверяет поля, а JavaScript добавляет Bootstrap-классы `is-invalid` и `is-valid`.

**4. Какие компоненты Bootstrap используются?**  
Navbar/Collapse, сетка, карточки, форма, таблица, Modal, Offcanvas, Accordion и Toast. Bootstrap CSS отвечает за оформление; Bootstrap JavaScript — за поведение готовых компонентов.

**5. Что делает собственный JavaScript?**  
Загружает JSON, выводит показатели и операции, проверяет форму, добавляет запись в память страницы, пересчитывает сводку и показывает уведомления.

**6. Как проверить после чистого клонирования?**  
Открыть корень проекта в VS Code, запустить `python -m http.server 8000` (или `py -m http.server 8000` в Windows), перейти на `http://localhost:8000` и проверить сценарии из README. Для CDN Bootstrap нужен интернет.

**7. Сохраняются ли добавленные записи?**  
Нет. Это учебный клиентский макет без сервера. Новая запись живёт только до перезагрузки страницы; кнопка обновления повторно загружает исходные JSON.

**8. Почему нужен Bootstrap Bundle?**  
В bundle-файле вместе с Bootstrap JavaScript включена зависимость Popper, необходимая некоторым компонентам. В проекте Bundle используется для Modal, Collapse, Offcanvas, Accordion и Toast.
